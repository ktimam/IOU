# IOU v1.1.4 — Mobile (Capacitor Android)

> Status: scaffolding. The Capacitor project is wired into the
> PWA build, the secure-storage adapter is in place, and the
> build commands are scripted. A real APK build requires
> Android Studio + the Android SDK on the build host (the dev
> WSL doesn't ship with it). The build commands and the
> troubleshooting steps are below.

## What you get

The PWA is wrapped in a native Android shell via
[@capacitor/core](https://capacitorjs.com) and
[@capacitor/android](https://capacitorjs.com/docs/android). The
shell uses the platform WebView (Android System WebView, which
is Chromium-based) to load the PWA's `dist/` bundle. The
service worker (from `vite-plugin-pwa`) continues to handle
offline caching inside the WebView.

The PWA's prod vetkd transport key is moved from IndexedDB to
the platform secure element
([@aparajita/capacitor-secure-storage](https://github.com/aparajita/capacitor-secure-storage))
on a real device — Keychain on iOS, Keystore + EncryptedSharedPreferences
on Android. The same key material works across web and mobile
because the IBE decrypt is the same.

## Files added

- `capacitor.config.ts` — the Capacitor config. App ID
  `com.iou.app`, webDir `dist/`, Android scheme `https`.
- `src/features/crypto/mobileSecureStorage.ts` — the
  `secureGet/Set/Del` adapter. On web it falls back to
  `localStorage`; on mobile it uses the platform secure element.
- `android/` — generated by `npx cap add android` (the
  Capacitor CLI does this on first run).

## Build commands

```bash
# 1. Install Android Studio (Windows host) and the Android SDK:
#    Android Studio -> SDK Manager -> install
#    - Android SDK Platform 35
#    - Android SDK Build-Tools 35.0.0
#    - Android SDK Platform-Tools (adb)
#    - Android SDK Command-line Tools (latest)
#    Then in the SDK Manager > SDK Tools tab, enable "Show
#    Package Details" and tick "Android SDK Platform 35" and the
#    build-tools for it.
#
# 2. Set the ANDROID_HOME and ANDROID_SDK_ROOT env vars:
#    export ANDROID_HOME="$HOME/Android/Sdk"     # Linux/macOS
#    setx ANDROID_HOME "%LOCALAPPDATA%\Android\Sdk"   # Windows
#    export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
#
# 3. Sync the PWA build into the Android project:
#    pnpm cap:sync
#    (This runs `pnpm build` and then `cap sync android`.)
#
# 4. Open the Android project in Android Studio:
#    pnpm cap:open:android
#    (or `npx cap open android` from the CLI.)
#
# 5. Build a debug APK:
#    pnpm android:build:debug
#    Output: android/app/build/outputs/apk/debug/app-debug.apk
#
# 6. Install on a connected device or emulator:
#    pnpm android:install
#    (Requires `adb` to see the device; plug in a phone with
#    USB debugging on, or start an AVD.)
```

## Production release (v1.1.5)

A v1.1.4 build is debuggable and unsigned. For a release you
need a signing key:

1. Generate a key:
   `keytool -genkey -v -keystore iou-release.keystore -alias iou -keyalg RSA -keysize 2048 -validity 10000`
2. In `android/`, edit `app/build.gradle` to add a `signingConfigs`
   block referencing the keystore (and load the creds from a
   `keystore.properties` file in the project root).
3. `./gradlew assembleRelease` produces
   `android/app/build/outputs/apk/release/app-release.apk`.

## Why Capacitor over a custom WebView

- One TS codebase, no React Native bridge tax.
- II (Internet Identity) works in modern WebViews.
- The PWA's service worker handles offline mode without
  Capacitor's `SplashScreen` / `WebView` shims.
- The same `dist/` build runs in the WebView, in a desktop
  browser, and in a desktop PWA install — so the same
  behavior is exercised in three environments.

## Troubleshooting

- **`gradle` can't find the Android SDK**: `ANDROID_HOME`
  isn't set. Run `echo $ANDROID_HOME` in the same shell you
  build from.
- **APK installs but II login fails**: the WebView is too old
  to support WebAuthn. Open Settings -> Apps -> IOU -> App
  Info -> "Update Android System WebView" (or update Play
  Services).
- **The build is huge (>50 MB)**: the WebView is shipping
  the full PWA. Strip the dev path (set `VITE_IOU_PROD_VETKD=1`
  in the build) and remove unused dev tooling from the bundle.
- **Capacitor complains about `cordova-android` not being
  found**: run `pnpm install` again; the install resolves it
  transitively.
