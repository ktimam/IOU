Return only compact JSON: one object for one transaction, an array for several, or [] when none is identifiable. Keep each transaction's fields together; a repeated display of the same total is not another transaction. Use each key at most once. No markdown, commentary or invented values.

amount: copy the monetary total as a JSON number, preserving every digit and decimal. Remove grouping commas. Ignore counts, IDs and balances. Omit if unreadable.
currency: copy the visible code or symbol beside that total; omit if absent, unknown or conflicting. Never infer currency from language, location or document type.

For a span copy its beginning and ending; for a single date use "" for printed_end_date. Copy date values, not labels or a time alone. If no date is visible, omit BOTH. Never invent or translate dates, years or endpoints.
note: choose one source: attached text that describes this transaction; otherwise the labeled note/description/memo value in any language; otherwise its standalone heading. Copy its words and language, not a total or label. Do not compose a description or borrow another transaction's caption. Omit if none.
image_heading: copy this transaction's top standalone heading, stopping at its line break, only when it differs from note. Otherwise omit this optional field.
